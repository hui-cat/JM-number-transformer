# 车牌号转换器

一个简单实用的在线工具，支持将数字按模板随机拆分插入文本，或从文本中提取数字。

## 功能

- **数字 → 文本**：输入一串数字，选择格式模板，点击确认即可将数字随机拆组并按顺序插入模板中
- **文本 → 数字**：输入含数字的文本，点击确认即可提取所有阿拉伯数字
- **格式模板**：内置多种预设模板（打战雷、打瓦、打GO、抽原神、抽鸣潮、抽明日方舟等）
- **快捷键**：`Ctrl+Enter` 快速触发转换
- **明暗主题**：支持手动切换明暗主题，也可跟随系统主题

## 使用方法

1. 在小文本框中输入数字
2. 从下拉框选择文本格式
3. 点击「确认」按钮或按 `Ctrl+Enter` 完成转换
4. 结果将显示在大文本框中
